# roadsheet

Printable contact/road sheet HTML report for caches in the current filter.  

This is a port of the GSAK RoadSheet macro, originally written by 
geo-mario.  Porting was aided by use of Google Gemini AI.

## What it needs

- OpenSAK with macro API version 3 or newer
- Permissions: open

Opens .html page in your default browser upon completion.

## How to use it

1. Set a filter to show (only) the caches to be printed to the roadsheet.
2. Run the macro from **Macros → Macro manager…**.
